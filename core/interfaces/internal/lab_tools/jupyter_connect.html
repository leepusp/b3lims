Use B3 LIMS data in Jupyter

This installation does not start Jupyter servers for you (that needs a Slurm cluster). Run Jupyter wherever you like and bring the data to it.

Today

  1. Open Samples, select what you need and choose Export Selected (Excel or CSV).
  2. Install Jupyter on your computer: pip install jupyterlab, then jupyter lab.
  3. Read the file with pandas: pandas.read_excel("samples.xlsx").

Planned: connect by API

A read-only API with personal access tokens and a small Python package (biobank_client) so a notebook can load samples, storage and metadata directly from this installation. It is on the roadmap and is not available yet.

Running a cluster?

Administrators of an HPC installation can turn on the Slurm launcher with BIOBANK_JUPYTER_ENABLED=true (see docs/hpc.md).
