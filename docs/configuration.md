# Configuration

`biobank-local setup` writes `config.env` in the data folder (permissions `600`, it holds the secret key). Edit it and restart to change a setting. Environment variables override the file.

## Local installation (`biobank.standalone_settings`)

| Variable | Default | Purpose |
|---|---|---|
| `BIOBANK_LOCAL_ROOT` | `~/.biobank-local` | Data folder (also `--root`) |
| `BIOBANK_SECRET_KEY` | generated by `setup` | Cryptographic signing key; keep it secret and stable |
| `BIOBANK_DATABASE_URL` | SQLite in the data folder | e.g. `postgres://user:pass@host:5432/biobank` |
| `BIOBANK_ALLOWED_HOSTS` | `localhost,127.0.0.1` | Comma-separated names people use to reach the server |
| `BIOBANK_CSRF_TRUSTED_ORIGINS` | empty | Public `https://` addresses when behind a reverse proxy |
| `BIOBANK_TIME_ZONE` | `UTC` | Time zone of dates shown |
| `BIOBANK_HOST` | `127.0.0.1` | Address `biobank-local run` listens on |
| `BIOBANK_DEBUG` | off | Django debug mode; never on a shared server |

Optional feature flags in this profile are off: `BIOBANK_HPC_ENABLED`, `BIOBANK_JUPYTER_ENABLED`, `BIOBANK_ONLINE_INTEGRATIONS_ENABLED`.

## Institutional deployment (`biobank.settings`)

| Variable | Purpose |
|---|---|
| `SECRET_KEY`, `DEBUG`, `ALLOWED_HOSTS`, `DATABASE_URL` | Standard Django settings |
| `BIOBANK_MEDIA_ROOT`, `BIOBANK_STORAGE_ROOT` | Uploaded files and persistent storage roots |
| `BIOBANK_GROUP_ROOT`, `BIOBANK_INVENTORY_ROOT`, `BIOBANK_SAMPLE_DOCS_ROOT`, `BIOBANK_MANIFESTS_ROOT`, `BIOBANK_SHARED_ROOT` | Sub-folders of the storage root |
| `BIOBANK_PAM_*` | PAM sign-in behind Apache (see [clusters](hpc.md)) |
| `BIOBANK_JUPYTER_*` | Jupyter servers started through Slurm |
| `BIOBANK_REPOSITORY_ROOT`, `BIOBANK_TAXONOMY_DIR` | Shared reference-data folders |
| `BIOBANK_ZENODO_TOKEN`, `BIOBANK_ZENODO_API` | Publishing to Zenodo (sandbox by default) |

See also [production deployment](operations/production.md).

## Reference data (taxonomy, GTDB, ICTV)

Organism lookups use local indexes so no web service is needed. Build them from the downloaded releases:

```bash
python manage.py build_taxonomy_index
python manage.py build_gtdb_index
python manage.py build_ictv_index
```

Without an index the fields still accept free text.
